== should format a property in a class ==
abstract   class   A   {
    x  =  1;
    [|a  :  string  =  "a";|]
    y  =  2;
}

[expect]
abstract   class   A   {
    x  =  1;
[|    a: string = "a";|]
    y  =  2;
}
