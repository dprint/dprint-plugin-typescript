== should not format the holding statement for a selection ending in the indentation of a closing bracket line ==
class   A   {
    m(  )  {
[|        a(  );
        b(  );
    |]}
}

[expect]
class   A   {
    m(  )  {
[|        a();
        b();|]
    }
}
