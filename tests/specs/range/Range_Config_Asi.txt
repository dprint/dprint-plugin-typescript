~~ semicolons: asi ~~
== should format a statement starting with a semicolon in a class body ==
class   A   {
    a  =  1
    ;[|[b]|]  =  2
    c  =  3
}

[expect]
class   A   {
    a  =  1
    ;[|[b] = 2|]
    c  =  3
}

== should format a statement starting with a semicolon in a switch case ==
switch   ( x )   {
    case   1:
        foo( )
        ;[|[1]|].forEach( x )
        bar( )
}

[expect]
switch   ( x )   {
    case   1:
        foo( )
        ;[|[1].forEach(x)|]
        bar( )
}
